// About Me

Chi Sono

Sono un IT Specialist con esperienza pluriennale nell'assistenza tecnica, gestione reti e amministrazione sistemi. Attualmente lavoro come IT Assistant & Network Specialist, occupandomi della gestione end-to-end dell'infrastruttura aziendale.

La mia esperienza include manutenzione hardware Dell, supporto help desk remoto, configurazione Active Directory, gestione infrastrutture di rete e troubleshooting sistemistico su commesse enterprise multi-sede.

Nel tempo libero mi dedico a progetti maker: stampa 3D, Arduino, Raspberry Pi, droni e fotografia. Sto imparando Python e CAD modeling, con particolare focus su Fusion 360 per la progettazione di componenti meccanici.

Ho frequentato Ingegneria Informatica presso l'Università di Firenze dal 2018 al 2024, dove ho sviluppato competenze avanzate in networking e sistemi distribuiti.

RackTemp

Monitor self-hosted per temperatura e umidità del rack: sensore ESP32-C3 + SHT31-D, dashboard web live con segnale WiFi, discovery automatica dei sensori in rete, aggiornamenti firmware OTA, alert SMTP/Telegram/Graph, backup programmati e integrazione PRTG/Prometheus/Zabbix. Disponibile come container Docker, servizio Windows o servizio Linux nativo.

TypeScript React ESP32-C3 Docker

GBP-Downloader

Tool web per l'ecosistema Game Boy Printer Emulator — zero installazione, gira interamente nel browser via Web Serial API. Riceve foto dalla Game Boy Camera via Arduino su USB, decodifica i tile 2bpp in PNG nativo (export singolo o batch ZIP) e flasha il firmware GBP Emulator su Arduino Nano/Uno via STK500v1, senza avrdude né Arduino IDE.

JavaScript Web Serial API Arduino
→ GitHub

DS Game Library

Tracker per la collezione di giochi Nintendo DS, precaricato con tutti i 3255 giochi ufficiali: spunta quelli che possiedi e tieni traccia della collezione da un sito statico.

JavaScript HTML CSS

PaperDesk

To-do list su display e-paper, controllabile da web app o bot Telegram. Basato su ESP32 (LOLIN32 Lite) e pannello e-paper 4.2", gira per settimane con una singola batteria LiPo grazie al deep sleep nativo.

ESP32 e-Paper Telegram Bot
→ GitHub

Threaded Insert Press

Pressa open source completamente stampabile in 3D per l'inserimento preciso di inserti filettati. Il progetto è stato realizzato in Fusion 360 con design parametrico che permette la personalizzazione di tutte le dimensioni. Include meccanica a vite senza fine per controllo fine della pressione, guide lineari per stabilità, e supporta diverse misure di inserti (M3, M4, M5, M6). Progetto rilasciato open source per la community maker e stampato da centinaia di utenti worldwide.

Fusion 360 3D Print Open Source

CosplayRPG

Badge RPG indossabile con ESP-01S e display OLED 0.96". Genera una carta personaggio RPG deterministica dal nome (classe, livello, statistiche), mostra eventi cosplay italiani in tempo reale da cosplayersitaliani.it, orologio NTP sincronizzato e WiFi captive portal per configurazione. Carousel automatico con alert per eventi imminenti. Progetto completo Arduino/ESP8266.

ESP8266 Arduino IoT OLED
